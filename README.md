# Ball Dodging Game

Unity로 제작 중인 공 피하기 게임 프로젝트입니다.

## 개발 환경

- Unity 6000.3.21f1
- Universal Render Pipeline (URP)
- Input System 패키지

## 프로젝트 구조

```
Assets/
  Scenes/       씬 파일
  Scripts/      게임플레이 스크립트
  Settings/     URP 렌더 파이프라인 설정
```

## 시작하기

1. Unity Hub에서 Unity 6000.3.21f1 버전 설치
2. 이 저장소를 클론한 뒤 Unity Hub에서 프로젝트 열기
3. `Assets/Scenes/SampleScene.unity` 씬 실행

## 상태

현재 초기 프로젝트 세팅 단계입니다.
