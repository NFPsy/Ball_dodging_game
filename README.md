# Ball Dodging Game

Unity로 제작한 3D 공 피하기 미니게임입니다. 5x5 격자 위에서 하늘에서 떨어지는 공을 피해 최대한 오래 버티고, 시간이 지날수록 빨라지는 난이도를 끝까지 견디면 클리어합니다.

## 게임 방법

- **이동**: `W` `A` `S` `D` — 격자 한 칸씩 이동
- **일시정지**: 화면 우측의 Pause 버튼 클릭 또는 `P` 키
- 공이 떨어질 위치에는 미리 빨간 경고 마커가 표시됩니다.
- 공에 맞으면 **Game Over**가 뜨고, `Y`(재시작) / `N`(종료)로 선택할 수 있습니다.
- 좌상단에 현재 생존 시간과 최고 기록(High Score)이 표시됩니다. (최고 기록은 앱을 껐다 켜면 초기화됩니다)
- 아래 난이도 곡선을 끝까지 버티면 **Game Clear**가 뜨고, 아무 키나 누르면 게임이 종료됩니다.

## 난이도 곡선

| 시간 | 공 생성 간격 | 동시 생성 개수 |
|---|---|---|
| 0 ~ 40초 | 3.0초 → 1.5초로 점차 감소 (20초마다 0.75초씩) | 1개 |
| 40 ~ 60초 | 1.5초 고정 | 1개 |
| 60초 ~ | 1.5초 고정 | 20초마다 2개씩 증가 (3, 5, 7, 9, 11) |
| 11개 도달 후 | 1.0초로 전환 | 11개 고정 |
| 그 상태로 30초 생존 | - | - → **Game Clear** |

## 개발 환경

- Unity 6000.3.21f1
- Universal Render Pipeline (URP)
- Input System 패키지

## 프로젝트 구조

```
Assets/
  Scenes/       씬 파일 (SampleScene)
  Scripts/      게임플레이 스크립트
  Materials/    타일, 배경 머티리얼
  Textures/     배경 이미지 등
  Settings/     URP 렌더 파이프라인 설정
```

### 스크립트 설명

| 스크립트 | 역할 |
|---|---|
| `GameManager.cs` | 게임오버/클리어/일시정지 상태, 최고 기록을 전역으로 관리하는 정적 클래스 |
| `PlayerController.cs` | WASD 격자 이동, 공과 충돌 시 게임오버 처리 |
| `Spawner.cs` | 시간 기반 난이도 곡선에 따라 공을 랜덤 격자 위치에 생성, 착지 경고 마커 표시 |
| `Ball.cs` | 바닥에 닿은 공을 일정 시간 후 제거 |
| `SurvivalTimer.cs` | 생존 시간 표시 및 최고 기록 갱신 |
| `HighScoreText.cs` | 최고 기록 UI 표시 |
| `GameOverUI.cs` | 게임오버 화면, 재시작(Y)/종료(N) 처리 |
| `GameClearUI.cs` | 클리어 화면, 아무 키 입력 시 종료 처리 |
| `PauseButton.cs` | 버튼 클릭 또는 `P` 키로 일시정지/재생 토글 |

## 시작하기

1. Unity Hub에서 Unity 6000.3.21f1 버전 설치
2. 이 저장소를 클론한 뒤 Unity Hub에서 프로젝트 열기
3. `Assets/Scenes/SampleScene.unity` 씬을 열고 Play

기초 게임플레이(이동, 스폰, 충돌, 난이도, 승패, 일시정지, UI) 구현 완료. 추후 사운드, 이펙트, 다양한 맵 등 폴리시 작업 예정.
